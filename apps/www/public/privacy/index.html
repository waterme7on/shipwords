Privacy

This is a self-hosted copy of the shipwords project website. It has no accounts, no forms and no newsletter, so it never asks for your name or email.

Analytics

This copy does not load analytics. The upstream project site at shipwords.dev uses Google Analytics 4 and Rybbit; that code is still in the repository, but the host check keeps it off this domain.

Sites built with shipwords

Each site built from this code, including tinydeskai.io, is run by its owner and has its own privacy policy.
